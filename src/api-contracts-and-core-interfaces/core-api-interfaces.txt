An inference api interface is the primary way an app sends work to an openai model and recieves a result.

Use this question to guide the decision:
What does the workflow need the API interation to do reliably?

For choosing an inference interface (first, and then state approach):
What does the app need to do?
Does it need predicatable structured output?
Does it need tool use?
Does it need continuity across turns?
Is the customer starting from an existing implementation that creates compatibility or migration constraints?
