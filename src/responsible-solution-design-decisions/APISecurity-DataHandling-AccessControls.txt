Identify data movement:
Weak statement:
The API uses support data and returns a summary.

Stronger statement:
The API receives support ticket title, description, requester role, priority, product area, and internal notes from the helpdesk system. It generates an internal triage summary and recommended next action. It writes the generated summary back to the ticket record only after staff confirmation. It logs request ID, timestamp, endpoint, status code, latency, and error category. It excludes ticket body, requester details, secrets, and generated narrative from application logs.
